CNKI-Hover · 使用说明（Windows x64）
================================================

■ 安装（推荐：双击安装包）
  运行 CNKI-Hover-Setup-1.1.0.exe → 一路回车即可。
  默认装到 %LOCALAPPDATA%\Programs\CNKI-Hover，
  会自动建好「开始菜单」和「桌面」快捷方式，并在「添加/删除程序」里登记卸载项。
  不需要管理员权限，也不需要 Python 环境。

  不想安装的话，也可以解压 CNKI-Hover-1.1.0-win-x64.zip 后直接双击 CNKI-Hover.exe。

■ 首次登录（零配置，不需要手写任何配置文件）
  1. 双击 CNKI-Hover.exe，托盘出现图标，并弹出登录窗；
  2. 「机构」一栏直接敲你的学校名 —— 程序会从 CARSI 联邦取回全国高校清单
     （约 8000 所；首次联网几秒，之后用本地缓存），边打边自动补全；
  3. 选中自己的学校 → 填学号/工号 + 统一身份认证密码 → 点登录。

  登录成功后程序会自动记住你的机构；登录态加密保存在本机（约 30 天），
  之后开机即用、长期免登录。凭证只用于当次向学校认证，不会保存明文。

■ 日常使用
  全局热键 Alt+Space 唤出悬浮搜索条 → 输入关键词 → Enter 或单击打开论文。
  · ↑↓ 或鼠标悬停：移动高亮
  · 鼠标滚轮：像聊天记录一样滑动列表
  · Esc：从阅读窗返回；Tab：切换「HTML 阅读 / 原版阅读」
  · 输入框左侧下拉框：选检索项（主题/篇名/关键词/摘要/作者/单位/来源）

■ 合规提醒
  仅限本人机构账号、个人学习使用；请勿批量下载、二次分发或用于商业用途。
  取全文会消耗你机构的下载额度（应用有本地缓存，同一篇不会重复下载）。
